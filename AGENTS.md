# SMM Workspace

Локальный контент-план и аналитика по площадкам. Спецификации в `docs/spec/`. Локальная инструкция в `docs/dev/setup.md`.

- Стек: Node.js 24, React, TypeScript, Vite, IndexedDB. Бюджет первой версии 0 ₽. Платные сервисы подключаются только по явному согласию владельца.
- Команды: `npm ci`, `npm start`, `npm run check`, `npm run test:e2e`. Новый запуск браузерных тестов создаёт чистый профиль. Остановка локального процесса — Ctrl+C.
- Работа в `main`. Отдельная ветка создаётся по явной просьбе. Коммиты на английском.
- Размещай код по возможностям, когда они разрастутся. Используй названия сущностей из требований. Ошибки показывай пользователю кратко, данные для диагностики сохраняй только без личных сведений.
- Подтверждай результат наблюдаемым поведением. Исправляй причину упавшего теста. Изменение согласованного критерия оформляй отдельно.
- При изменении возможности или экрана сначала обнови соответствующий сценарий в `docs/spec/04-user-flows.md`, затем меняй код.
- Тесты используют вымышленные данные. Рабочие CSV, резервные копии и токены держи вне папки проекта. Секреты MCP хранятся в настройках самого коннектора. Публичные сборки и снимки используют только демонстрационные данные.
- Проверь зависимости и секреты перед публикацией. Мини-скиллы продублированы в `.agents/skills/` и `.claude/skills/`. Обновляй обе копии.

## Правила интерфейса

- Общая тема и правила космического оформления описаны в `DESIGN.md`.

- Для кнопок, карточек, форм, вкладок, таблиц и диалогов сначала используй Mantine. Календарь публикаций и доску собирай из общих компонентов проекта.
- Цвета, шрифты, скругления и отступы бери из токенов темы Mantine.
- Используй иконки Lucide. Декоративные иконки скрывай от программ чтения с экрана. Действия с одной иконкой снабжай доступным именем.
- Экраны текущего этапа получают тестовые данные через `src/lib/stubs/`. После подключения хранилища сохраняй контракты экранов.
- Собирай обычное, пустое, загрузочное и ошибочное состояния по карте сценариев. Каждый собранный пользовательский путь проверяй в Playwright.
