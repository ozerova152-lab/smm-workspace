## Описание

Связать экран резервной копии с постоянным хранилищем. Восстановление сохраняет версию схемы и применяет полный набор атомарно. Проверить перенос замеров с окнами сравнения из T04 и чтение копии первоначального формата. Прогнать тест с двумя профилями и повторным запуском. Отдельно проверить переключение между рабочим и демонстрационным режимами.
