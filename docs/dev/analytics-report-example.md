# Отчёт для проекта «Городской сад»

Пример на вымышленных данных. Оба замера взяты из одного источника «Пример» за 18–24 ноября 2026 года. Ссылки в таблице условные.

| Публикация | Источник | Окно замера | Просмотры |
|---|---|---|---:|
| «Зелень на балконе» | Пример | 18–24 ноября 2026 | [150](https://example.com/garden/balcony) |
| «Рассада на подоконнике» | Пример | 18–24 ноября 2026 | [95](https://example.com/garden/seedlings) |

За этот период ролик «Зелень на балконе» набрал на 55 просмотров больше. По двум роликам можно предложить следующую гипотезу для проверки.

**Идея для плана** — «Три способа вырастить зелень на маленьком балконе».

**Содержание** — показать три ёмкости разного размера, назвать подходящие для каждой виды зелени и объяснить, куда поставить ёмкость. После выхода сверить просмотры за первую неделю с другими короткими роликами по замерам из того же источника.

Чтобы проверить перенос вручную, откройте контент-план и нажмите «Добавить идею». Введите заголовок и содержание, сохраните карточку и откройте её из плана.
